# 七面心镜

一份注重隐私、尊重与可解释性的七宗罪倾向测试。35 道题会从七个维度描绘当前状态，并以 SVG 雷达图、逐维解读和具体建议呈现结果。

> 这是一项娱乐与自我反思练习，不是心理诊断、人格定论或道德评判。

## 在线体验

https://mingrenj.github.io/aiti-test/seven-mirrors/

## 功能

- 35 道混排情境题，每个维度 5 题，包含反向计分
- 七维 0—100 倾向雷达图及文本等价信息
- 主倾向、双核心倾向、相对调节资源与具体行动建议
- 自动保存答题进度，刷新后可继续
- 一键生成 1080 × 1350 PNG 结果卡
- Web Share / 剪贴板分享
- 键盘作答、清晰焦点、减少动态效果与移动端适配
- 零依赖、零后端、零数据上传

## 本地运行

这是一个原生 HTML / CSS / JavaScript 静态站点。为了让 ES Modules 正常加载，请通过任意静态服务器预览，例如：

```bash
npx serve .
```

然后打开终端显示的本地地址。

## 验证

```bash
npm test
npm run check
```

测试会检查题库数量、维度分布、反向题数量、计分上下界、中性答案和结果排序规则。

## 计分方法

每道题使用 1—5 量表。正向题直接计分，反向题使用 `6 - 答案`。每个维度的 5 道题取平均后换算为 0—100：

```text
score = round(((average - 1) / 4) × 100)
```

- 0—34：相对舒缓
- 35—64：情境触发
- 65—100：较为鲜明

分档只描述倾向强弱，不表示正常/异常或善/恶。

## 隐私

所有答案和结果只写入当前浏览器的 `localStorage`，不会发送到任何服务器。分享图也完全在浏览器内生成。
