# 七面心镜

一份注重隐私、尊重与可解释性的「七宗罪 × 七美德」光影人格测试。系统会从 98 题题库中按 seed 抽取 28 道核心题，并视答案一致度追加至多 14 道校准题，最终呈现 14 个独立分数和 7 组人格张力。

> 这是一项娱乐与自我反思练习，不是心理诊断、人格定论或道德评判。

## 在线体验

https://mingrenj.github.io/aiti-test/seven-mirrors/

## 功能

- 98 题可扩展题库；每次固定 28 题核心轮廓，按规则自适应至 28–42 题
- 7 个宗罪与 7 个美德独立计分，美德不是 `100 - 宗罪`
- 双层七轴光谱、完整文字分数和 7 组张力状态
- 主宗罪与主美德双使者结果，覆盖 49 种稳定组合叙事
- seed、题组、答案与追加题均自动保存在浏览器，刷新后可继续
- 14 位透明「棱镜蚀刻」使者及图片失败时的几何光印回退
- 一键生成 1080 × 1350 双使者 PNG 结果卡
- Web Share / 剪贴板分享
- 键盘作答、清晰焦点、减少动态效果与移动端适配
- 零依赖、零后端、零数据上传

## 本地运行

这是一个原生 HTML / CSS / JavaScript 静态站点。为了让 ES Modules 正常加载，请通过任意静态服务器预览，例如：

```bash
npx serve .
```

然后打开终端显示的本地地址。

## 计分方法

每道题使用 1—5 量表。正向题直接计分，反向题使用 `6 - 答案`。每个维度的 2–3 道题取平均后换算为 0—100：

```text
score = round(((average - 1) / 4) × 100)
```

- 两端均 ≥65：双高张力
- 两端均 ≤34：暂低激活
- 美德分减宗罪分 ≥20：美德资源鲜明
- 美德分减宗罪分 ≤-20：阴影拉力鲜明
- 其他：动态平衡

分档只描述倾向强弱，不表示正常/异常或善/恶。

## 隐私

所有答案和结果只写入当前浏览器的 `localStorage`，不会发送到任何服务器。分享图也完全在浏览器内生成。
