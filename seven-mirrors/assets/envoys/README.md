# 光影使者资产

正式视觉方向：**B「棱镜蚀刻」**。所有角色由 built-in imagegen 独立生成，并以「傲慢 / 谦逊」定稿作为统一风格参考。

## 生产规格

- 原始归档：`originals/{key}.png`，1122 × 1402，透明 ARGB。
- 网站版本：`{key}.webp`，768 × 960，透明 WebP；不裁切等比缩放。
- 构图：成人、性别中性、无写实脸、上半身、安全边距。
- 朝向：7 位宗罪朝右，7 位美德朝左，以便结果页左右相望。
- 宗罪光路：收束、断裂、尖锐；暖金、朱色及维度强调色。
- 美德光路：开放、连续、舒展；冷白、青金及维度强调色。
- 禁止：文字、水印、宗教审判符号、裸露、武器、妖魔化或医学化外观。
