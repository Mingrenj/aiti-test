# 光影使者资产

正式视觉方向：**B「棱镜蚀刻 · 动作叙事版」**。所有角色由 built-in imagegen 独立生成，以动作和身体轮廓优先表达心理特征，不再依赖换色或胸前光球区分人格。

## 生产规格

- 原始归档：`originals/{key}.png`，1122 × 1402，透明 RGBA。
- 网站版本：`{key}.webp`，768 × 960，透明 WebP；不裁切等比缩放。
- 构图：成人、性别中性、无写实脸、上半身至腰下、四周透明安全边距。
- 朝向：7 位宗罪朝右，7 位美德朝左，以便结果页左右相望。
- 宗罪光路：收束、断裂、尖锐；暖金、朱色及维度强调色。
- 美德光路：开放、连续、舒展；冷白、青金及维度强调色。
- 禁止：文字、水印、宗教审判符号、裸露、武器、妖魔化或医学化外观。

## 角色提示词主题

| key | 视觉语义 |
| --- | --- |
| `pride` | **折返**：高举碎镜，把所有视线折回自身 |
| `humility` | **打开**：双手转开棱镜，让外部视角进入 |
| `greed` | **收拢**：从外界拉回光丝，在胸前编成牢笼 |
| `generosity` | **送出**：引导连续光流离手，并在外部增殖 |
| `lust` | **追逐**：身体与双手被多路刺激同时牵引；不性感化 |
| `chastity` | **划界**：建立透明边界，并主动收回散乱光带 |
| `envy` | **丈量**：比较他者星光，同时遮挡自身仍有的光 |
| `kindness` | **托高**：让他者星光升高，同时保留自己的独立星光 |
| `gluttony` | **继续填入**：容器已经满溢，双手仍推动更多光流；不使用体型或食物 |
| `temperance` | **校准**：控制双容器之间的稳定窄流，并导回多余部分 |
| `wrath` | **击碎**：拳面击破棱镜，冲击与碎片向外扩散 |
| `patience` | **转化**：双手依次承接尖锐波纹，将其变为同心环 |
| `sloth` | **停在连接前**：手已伸出，却停在最后一个节点之前；无疾病、残障或抑郁暗示 |
| `diligence` | **完成连接**：嵌入零件并拉紧连续光线，留下完成轨迹；不赞美过劳 |
