# 七面心镜 v2｜产品需求文档

## 产品定位

面向 16 岁以上大众的「七宗罪 × 七美德」光影人格测试。产品用于娱乐和自我观察，不提供善恶总分、医学判断或人群排名。全站无账号、无后端、无统计；答题内容仅保存在浏览器本地。

对应美德采用现代产品化映照：谦逊、慷慨、贞洁、善意、节制、耐心、勤勉。页面需明确说明：七宗罪与美德在历史传统中存在多种体系，本产品选择的是一组便于自我观察的当代对应关系，并非唯一官方配对。

## 测评体验

- 独立计算 7 个宗罪与 7 个美德，共 14 个倾向值。
- 第一阶段每个维度随机抽取一正一反、且类别不同的题，共 28 题。
- 完成后进入校准阶段：若某维度两次校正后答案相差至少 2 级，或初步分数距离 35/65 边界不超过 10 分，则追加该维度第 3 题。
- 最多追加 14 题，总题数为 28–42。追加列表生成后冻结，返回修改答案不再增删题目。
- 测试生成可复现 seed；刷新和中途退出保持同一题组、顺序与进度；重新测试才生成新 seed。
- 量表采用 1–5 分；反向题按 `6 - answer` 校正；维度均值映射为 0–100。

## 题库与数据

- 首版题库 98 题，14 个维度各 7 题，包含自述题、调节题和情境题。
- 稳定 ID 永不复用；停用题使用 `active:false`，不删除历史 ID。
- 全局混排时不允许相同维度相邻，也不允许连续超过 2 题属于同一 family。
- v2 状态使用独立键 `seven-mirrors-state-v2`，保存 bankVersion、seed、phase、核心题/校准题 ID、currentIndex、answersById、scores 和 completedAt。
- 保留 `seven-mirrors-state-v1`。已完成旧结果提供归档入口；进行中的旧测试只提示重新开始，不迁移为十四维结果。

## 七组张力

每组派生 `balance = virtueScore - viceScore` 与 `activation = (virtueScore + viceScore) / 2`：

1. 傲慢·认可需求 ↔ 谦逊·开放与如实看待自己
2. 贪婪·稀缺感 ↔ 慷慨·分享与充足感
3. 欲望·刺激寻求 ↔ 贞洁·边界与自持
4. 嫉妒·比较心 ↔ 善意·欣赏与共情
5. 暴食·过度满足 ↔ 节制·适度与觉察
6. 愤怒·怒火反应 ↔ 耐心·情绪容纳
7. 懒惰·行动惰性 ↔ 勤勉·稳定行动力

状态依次判断：两者均 ≥65 为「双高张力」；两者均 ≤34 为「暂低激活」；balance ≥20 为「美德资源鲜明」；balance ≤-20 为「阴影拉力鲜明」；其余为「动态平衡」。最高分并列按回答数量、答案一致度、固定维度顺序决胜。

## 结果结构

1. 光影人格首屏：最高宗罪与最高美德两位使者同框；同组为「同轴映照」，异组为「交叉双核」；提供组合称号与解释。
2. 双层七轴光谱：宗罪使用暖金/朱色实线光轨，美德使用冷白/青金光轨；两层可独立显示/隐藏；同时提供完整文本数值。
3. 七组张力卡：展示双侧分数、balance、activation、状态与可执行建议。
4. 完整结果：14 维独立分数、优势、失衡风险、分档建议，以及 3 条联合行动建议。
5. 分享：下载 1080×1350 双使者 PNG、复制文案、调用系统分享、重新测试。

## 光影使者视觉系统

- 性别中性、当代神秘学、透明背景发光线稿、无写实脸、无宗教审判符号。
- 宗罪采用收束、断裂、尖锐光路；美德采用开放、连续、舒展光路。
- 欲望不使用裸体或挑逗姿势；暴食不以体型表达；懒惰不使用疾病、残障或抑郁外观。
- 首屏仅预加载两位主角，其余 12 张懒加载；加载失败回退为代码生成的几何光印。
- 展示层提供锐利线稿、模糊辉光、遮罩扫光与轻微呼吸；`prefers-reduced-motion` 下静态显示。
- 正式角色生产前先提供「纤维光丝 / 棱镜蚀刻 / 星图几何」三张傲慢 × 谦逊概念板供确认。

已确认视觉决策（2026-10-27）：选择 **B「棱镜蚀刻」**。结果首屏采用宗罪在左、美德在右的双栏半身像，两位使者彼此相对；移动端仍保持左右关系，并以安全边距避免头部、肩部和手部被裁切。
